# 午夜捉迷藏契约：叙事背景定稿

日期：2026-09-12  
状态：用户已确认背景；首版开场动画与动态标题已接入。结算的叙事呈现尚未接入。

## 目标与范围

为现有黑暗房屋追逐提供少量背景，帮助玩家理解自己是谁、为什么追逐，以及胜负意味着什么。体验以「紧张好玩」为主，带轻度恐怖。

用户进一步确认以角色与场景语言承载叙事，优先制作首次进入时自动播放的开场动画和动态标题，避免大段文字。不改变现有玩法、角色分配方式、胜负条件或资源规则，不增加调查、收集、章节、支线或新目标。不扩展人物身世与契约起源。

现有规则与领域用语以 [CONTEXT.md](../CONTEXT.md) 为准。以下设定为规则提供故事解释，不新增机制。

## 核心背景

放学后，几个孩子为了证明胆量，接受挑战，进入传闻闹鬼的空屋。他们发现一张捉迷藏规则，念出最后一句后，无意间触发了午夜捉迷藏契约。

门被锁住，其中一个孩子被契约选中，失去意识。契约借他的身体行动，驱使他成为本局的鬼，完成三次抓捕。其他孩子必须撑过五分钟，或用手电驱散附在他身上的力量，才能结束契约并一起离开。

「午夜」是契约的名称与恐怖意象；不要求玩家等待现实午夜，也不增加游戏内时钟或触发条件。

### 鬼的身份

被选中的孩子不再回应同伴的呼喊，也无法自主配合或放水。鬼玩家控制的是契约中的鬼；孩子本人没有意识，不是主动追逐朋友以换取自由。

这解释了熟悉的同伴为什么构成真实威胁。背景不承担阻止真人玩家故意输掉对局的功能。

## 与现有规则的对应

| 现有规则 | 叙事解释与边界 |
| --- | --- |
| 对局持续五分钟；时间归零时小孩阵营获胜 | 契约的追逐期限是五分钟，撑到结束，门就会打开。 |
| 手电照射削减鬼生命；鬼生命耗尽时小孩阵营获胜 | 光削弱附在孩子身上的力量；将其驱散可以提前结束契约。鬼生命不解释为孩子本人的生命，获胜不意味着杀死同伴。 |
| 一次有效抓捕增加团队失败进度 | 契约记下一次抓捕，不意味着被抓的孩子死亡或淘汰。无需抓到三个不同的孩子。 |
| 抓捕结算后全部对局角色复位，保留生命、电量、电池与抓捕进度 | 契约把所有角色送回起点，但已经发生的消耗与抓捕仍然算数。第三次抓捕满足鬼获胜条件，故事不暗示还会开始第四轮追逐。 |
| 鬼完成三次抓捕后获胜 | 契约完成，所有孩子失去离开的机会；后续命运留白。 |
| 感应人偶填补空缺小孩槽位，只通过头灯反映鬼的距离 | 它们是屋里留下的旧玩偶，来历留白。不将它们描写成参与逃跑、被抓或影响胜负的同伴。 |

手电、头灯与闪电仍按现有规则区分：手电照射可以削弱鬼；头灯只表达距离；窗外闪电只使受直射的鬼显形。背景不将所有光源解释为具有相同效果。

## 定稿文案

### 开场背景文本（设计参考，不直接整段展示）

> 放学后，几个孩子为了证明胆量，走进了传闻闹鬼的空屋。  
> 他们找到一张捉迷藏规则，笑着念出了最后一句：  
> **「这一次，轮到你当鬼。」**  
>  
> 门锁响了。其中一个孩子垂下脑袋，不再回应自己的名字。  
> 随后，他的影子动了起来。

### 小孩阵营获胜

> 门开了。那个孩子醒了，问你们为什么还不回家。

时间耗尽与鬼生命耗尽共用这一结局：契约结束，被选中的孩子恢复意识。

### 鬼获胜

> 门没有打开。墙上，多了一张你们的合照。

合照是结算中的恐怖暗示，不要求新增拍照、收集或场景变化机制。不解释孩子们具体变成了什么，也不确认感应人偶就是过去被困的孩子。

## 已确认的视觉接入

首次进入、资源就绪后自动播放约八秒的无字演出；无需玩家触碰，也不依赖声音。原背景中的「念出规则」在镜头中简化为靠近桌子、触碰旧纸，以可见动作交代误触契约。

| 时间 | 场景表达 |
| --- | --- |
| 0–2 秒 | 三个孩子围着旧纸，一人靠近桌沿伸手触纸，三个暗红手印浮现。 |
| 2–4 秒 | 门关闭，触纸的孩子收手、垂头，失去意识；同伴后退。 |
| 4–6 秒 | 墙影独立转动；同伴举起手电，附身力量以现有鬼模型显现。 |
| 6–8 秒 | 鬼避开光束，镜头退开，标题与「开始游戏」浮现。 |
| 8 秒后 | 保留灯具摇晃、角色微动与鬼的起伏，等待玩家主动进入大厅。 |

开场是独立的展示场景，不创建对局、不随机分配实际玩家角色。使用三名演出角色不改变对局固定四个小孩槽位的规则。

已实现的行为：

- 首次自动播放；看完或跳过后在本机记录已观看，后续直接进入原大厅。
- 全程可跳过，Escape 可退出；首页标题下和房间等待页提供「观看开场动画」，动画结束的标题页提供「再看一遍」，可以主动连续重复观看。
- 房间链接、已有房间会话、开发用确定性场景与场景编辑/试玩入口绕过开场。
- 切到后台时暂停演出计时；系统开启减少动态效果时，首次自动开场直接展示静止标题场景。用户主动点击观看或再看一遍时从头播放动画，已观看记录只控制自动播放。
- 资源失败时返回原大厅；加载过程中也能跳过。演出不会自动开始真实对局。
- 桌面、手机竖屏及紧凑横屏分别适配构图和标题安全区域。

代码入口：[OpeningSequence.ts](../src/game/OpeningSequence.ts) 管理播放、跳过与标题状态；[OpeningScene.ts](../src/game/OpeningScene.ts) 管理角色动作、镜头与场景。复用现有渲染循环、KayKit 角色和家具，以及房屋材质；没有新增下载资源或修改资产许可记录。

## 后续呈现约束

- 开场保持简短，服务于进入对局；不制作长剧情或强制观看的演出。
- 规则提示继续准确说明五分钟、三次抓捕与手电作用，恐怖措辞不能遮蔽实际胜负条件。
- 结算保留阵营胜负信息，再展示对应故事文案；鬼阵营获胜不写成被选中孩子获得自由。
- 关门、影子、触纸与手电已在开场中以画面呈现；当前演出为静音，不新增开场音效。
- 局内抓捕手印、复位纹样，以及结算开门/合照的视觉呼应属于后续工作，本次仅实现开场和动态标题。
