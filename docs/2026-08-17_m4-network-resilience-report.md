# M4 局域网韧性与平滑报告

## 断线语义

- 小孩在对局中断线后立即调用规则引擎的 active 切换：不再移动、照射、阻挡或成为抓取目标，并在所有仍在线视角中变为同位置的感应人偶。
- 服务端保留该玩家的角色、位置、个人电量和重连令牌 30 秒；重新连接后恢复同一玩家 ID，并从人偶切回真人。
- 超过 30 秒后令牌失效，人偶保留到本局结束；不会补 AI，也不会替断线玩家移动或照射。
- 鬼在对局中断线时立即取消本局、不产生胜负，移除该席位并把其余玩家带回大厅。
- 浏览器只把临时房间会话写入 `sessionStorage`，用于刷新页或短时掉线恢复；没有账号、数据库或长期存储。

## 权威循环与输入

- 服务端使用 60 Hz 固定步长累加器，单次最多追赶 5 步，避免局部卡顿造成无限追帧。
- 输入超过 250 ms 未刷新即自动归零；序号倒退、错误 match ID、非法数值和客户端位置仍被拒绝。
- 每个连接的帧继续单独投影和定向发送，重连不会获得完整 checkpoint 或历史隐藏坐标。
- 事件以 `matchId:eventId` 去重，缓存上限 512，避免恢复或重复投递造成二次表现。

## 客户端表现

- 本地拥有的角色按同一移动速度和静态墙体做即时预测；服务端误差小于 1.25 单位时渐进纠偏，超过阈值硬回正。
- 远端孩子、娃娃、可见鬼与电池在相邻 20 Hz 帧间插值；预测不会作用到其他玩家。
- 诊断数据暴露未确认输入数、确认延迟、帧年龄、插值进度、渐进纠偏次数和硬回正次数。

## 验收证据

- 真实 Socket 测试验证输入过期、孩子断线转四个人偶、凭令牌恢复同一 ID，以及鬼断线回大厅。
- 浏览器测试验证刷新页后自动恢复同一个孩子角色，并在鬼页关闭后显示大厅取消原因。
- 单元测试验证本地预测/远端插值、墙体预测碰撞、硬纠偏和事件去重。
- `npm run build`、`npm run test:rules`、`npm run test:browser` 均通过。
