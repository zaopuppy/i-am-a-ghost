# M2 权威房间链路报告

## 交付结果

- Socket.IO 权威房间支持 2–5 名局域网玩家，创建/邀请码加入/房主开始均已接通。
- 服务端以 60 Hz 驱动 `MatchEngine`，按 20 Hz 向每个连接定向发送视角帧。
- 输入协议只接受当前连接自己的 ESDF、朝向与空格意图；递增序号拒绝过期输入，客户端不能提交玩家 ID 或坐标。
- 一局随机分配一名鬼，其余真人为小孩；空余的小孩槽位由感应人偶补齐。
- 孩子视角在未照中时没有鬼对象，更不会收到完整 checkpoint、随机数或隐藏动作字段；任一光束命中后，所有孩子帧才包含鬼的位置。
- PC 浏览器已接入自动临时昵称、六位房间码、房间名单、开始按钮和实际 ESDF 输入路径。

## 验收证据

- `npm run build`：通过。
- `npm run test:rules`：26 项通过，包含视角投影、双 Socket 客户端、过期输入拒绝。
- `npm run test:browser`：双浏览器页面能够创建、加入、开始并通过权威链路移动；大厅画布及服务健康检查通过。

## 当前边界

M2 使用基础占位角色与静态全屋镜头，只验证联机、安全过滤和控制闭环。完整房屋灰盒、双视角镜头、灯光/HUD、抓取反馈与结算在 M3 实现。
