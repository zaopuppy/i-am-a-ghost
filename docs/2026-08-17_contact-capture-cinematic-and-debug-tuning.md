# 接触抓取、抓捕演出与开发调参

日期：2026-08-17

## 设计契约

- 玩家承诺：鬼只需要追上并碰到孩子；被抓的一刻必须像一次真正的惊吓，而不是一次数值判定。
- 目标感受：追逐规则直接、接触结果明确、抓捕短暂而强烈。
- 核心循环：鬼追逐并接触孩子，孩子用移动和手电拉开距离；接触触发抓捕演出，三次抓捕后鬼获胜，鬼被照灭或时间耗尽则孩子获胜。
- 技能表达：鬼判断路线和堵口，孩子管理距离、手电与电池；不再考验鬼的鼠标方向锥或空格时机。
- 非目标：本轮不新增鬼的攻击动画资产、不改变地图、不重做孩子骨骼动画。

## 规则变更

- 主动抓取、21 tick 前摇、抓空冷却、1.4m/90°方向锥全部移除。
- 双方碰撞壳层接近到 `0.98` 世界单位时，服务器立即选择最近的 active child 并完成抓取；判定与鬼的鼠标朝向、空格状态无关。
- 鬼的服务端朝向由移动方向产生；小孩仍以鼠标方向控制手电。
- 抓捕演出从 90 tick 延长到 156 tick（2.6 秒）。第三抓也先完整演出，再进入结算。
- 同 tick 内仍先结算手电伤害与孩子胜利，再结算接触抓取。

## 抓捕呈现

- 帧中新增窄化的 `capture` 演出数据：目标 child ID、剩余 tick、总 tick；不暴露原始 checkpoint 私有字段。
- 被抓小孩在抓捕期看见鬼；其他小孩继续看不到未被照亮的鬼，避免泄露位置。
- 程序化鬼增加双臂、手掌、抓捕光环和冷色点光。抓捕时鬼从背后环抱目标，只有目标播放 `Hit_A`。
- 鬼和被抓小孩的镜头聚焦两人并快速收紧到 `5.2` view height；其他小孩镜头不被强制拉走。
- 抓捕事件触发现有 CC0 瞬态，并叠加确定性的 Web Audio 低频下坠、尖啸和带通噪声刮擦。ElevenLabs 探针为 `MISSING`，因此本轮没有生成外部音频文件。

## 镜头与开发调参

- 小孩默认镜头由 `10.5` 拉远到 `12.5`。
- Vite 开发模式动态加载 `lil-gui`；确定性截图与生产构建不加载面板。
- 可实时调整小孩/鬼/抓捕镜头距离、普通跟随速度、抓捕拉近速度、小孩速度和鬼速度。
- 移动速度由房主通过仅开发服务器开放的 socket 消息写入房间权威 `MatchEngine`，并广播给其他客户端用于一致的本地预测；生产服务器拒绝该消息。

## 验证

- 规则与服务器测试：49/49。
- Playwright 浏览器测试：12/12。
- 视觉基线：更新 `child-playing`、`low-battery`、`capture`；抓捕基线明确显示双臂环抱和特写镜头。
- 双页联机验证：房主把小孩速度实时改为 `5.25` 后，访客收到相同权威调参。
- 生产构建中检索不到 `lil-gui`、`开发调试` 或调参控件文案。
