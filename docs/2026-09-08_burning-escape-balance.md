# 灼烧逃脱速度调整

鬼受照后原本以常速的 80% 移动（3.168），低于小孩常速（3.6）。7.5 的手电射程下，小孩持续追照会让鬼难以拉开距离。

灼烧移动倍率改为 1.4：鬼常速保持 3.96，灼烧时为 5.544。首次被照射的规则步即生效，脱离照射后沿用现有 90 步（1.5 秒）灼烧余效，结束后恢复常速。灼烧仍禁止抓捕，照射伤害、生命和手电射程沿用原值。

单人、房间服务器和局域网权威规则使用同一倍率；联机本地移动预测也读取该倍率。

回归覆盖开阔地相距 1.5 时，小孩保持满速同向追照，鬼能够在死亡前脱离手电范围；同时验证受照加速、余效期间加速、余效结束恢复常速及灼烧禁止抓捕。构建和 157 项规则测试通过，另运行 1–4 个小孩各 4 局自动平衡模拟。模拟不等同于真人胜率，本次目标是提供逃脱空间，不保证低血量或多人包围时也能逃脱。

本记录取代历史设计文档中的“手电命中使鬼减速 20%”规则。
