```
《不要被抓到》是一款仅支持 2 至 5 名真人、在同一局域网内联机的非对称俯视角追逐游戏。本版本专为华为内部 GameHack 比赛体验评分提供，不对外正式上架，不含账号注册、付费、广告或公网匹配。

游戏发生在一栋黑暗房屋中：系统随机指定一名玩家为鬼，其余玩家为小孩。鬼能俯视整栋房屋并看到所有小孩位置，需要在 5 分钟内累计完成 3 次抓捕；小孩只能看到附近房间，需要用窄手电光束持续照射鬼，并靠头灯闪烁判断鬼的远近。小孩把鬼的生命照到归零，或撑过 5 分钟倒计时，小孩阵营获胜。空缺的小孩位置由不会移动的感应人偶占位，只用于提示距离。

本机无需登录。启动后需先同意本次运行使用局域网能力，然后由一台手机创建房间，其他手机通过附近房间列表、扫描二维码或输入 6 位房间码加入。房间码仅用于同一 Wi-Fi 下组房，不是注册邀请码。对局过程使用虚拟摇杆移动；小孩按住「手电」照射，鬼接触小孩后自动抓捕。切到后台或退出应用会停止局域网发现与连接。

本游戏定位为短局、可爱惊悚的局域网对战，不含血腥暴力、语音聊天、养成或商业化内容。
```

### 1.3 测试说明

```
【用途】本包仅供华为内部 GameHack 比赛体验评分，不对外上架。无账号、无付费、无公网匹配，无需测试账号。

【环境】请准备 2–5 台 HarmonyOS 手机，连同一 Wi-Fi（勿用访客网/AP隔离）。单机无法点「开始游戏」，属正常。切后台或退出会停止局域网。

【步骤】
1. 启动后勾选局域网说明，再点「创建房间」。
2. 其他手机勾选同一说明后，从「附近游戏房间」点入；或扫房主二维码；或输入 6 位房间码点「加入」。
3. 满 2 人后，房主点「开始游戏」。系统随机 1 名鬼、其余为小孩。
4. 左摇杆移动。小孩按住右下「手电」照射鬼；鬼接触小孩自动抓捕。
5. 结算后点「准备下一局」。

【规则】单局 5 分钟。鬼抓捕满 3 次获胜；鬼生命归零或时间结束则小孩获胜。头灯只表示鬼的远近，不表示方向。

【权限】网络用于局域网组房。扫码走系统界面，拒绝扫码仍可手动输入房间码。无登录、定位、麦克风、通讯录。

【排查】附近列表为空时，请确认两台都已勾选同意、连同一 Wi-Fi、房主已创建房间，并等待数秒。房间码只用于同网组房，不是注册邀请码。本版为比赛试玩，平衡与稳定性仍在验证。
```

## 3. 审核员 / 体验员最短路径

1. 两台 HarmonyOS 手机连同一 Wi-Fi，不要用访客网络或 AP 隔离。
2. 两台都打开应用，勾选局域网说明。
3. A 点「创建房间」；B 从「附近游戏房间」加入，或扫码，或输入 6 位房间码。
4. A 点「开始游戏」。左摇杆移动；小孩按住右下「手电」；鬼接触小孩自动抓捕。
5. 单机只能验证启动、同意、创建房间和二维码，不能开局。这是规则，不是故障。
