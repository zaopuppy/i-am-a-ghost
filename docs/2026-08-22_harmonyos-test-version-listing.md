```
《不要被抓到》是一款黑暗房屋中的非对称追逐游戏，支持单人 AI 对局及 2 至 5 名真人同一局域网联机。本版本仅供内部 GameHack 比赛体验评分，不对外正式上架，不含付费、广告或公网匹配。

单人游戏可选择成为鬼或小孩，并设置 1 至 4 个小孩，其余参战角色由 AI 控制。多人房间由玩家自行选择阵营，所有人选定且恰好有一名鬼、至少一名小孩后，由房主开始游戏。空缺的小孩槽位由静止的感应人偶补齐，只提示鬼的距离，不参与抓捕或胜负。

每局 5 分钟。鬼能看到所有小孩的位置，累计完成 3 次抓捕获胜；小孩用手电持续照射鬼，使鬼生命归零，或撑到倒计时结束即可获胜。头灯闪烁只提示鬼的远近。鬼被照射后短暂加速且不能抓捕，需要脱离光束。移动端用左摇杆移动，小孩按住并拖动右摇杆照明转向，松手后转身跑。

启动需联网完成游戏服务初始化、平台账号登录及实名、防沉迷验证，成功后才能进入单人或多人游戏。无需在本应用另行注册账号。单人对局在验证通过、资源就绪后可离线运行，并支持暂停、重新开始及更换角色；不代表应用可免登录或断网启动。

多人联机需先同意本次运行使用局域网能力，再创建房间，或通过附近房间、扫码、6 位房间码加入。房间码仅用于同网组房，不是注册邀请码。联机菜单可切换声音、查看操作和退出房间，打开菜单不会暂停对局。房间主机退出会结束整个房间；切到后台或退出应用会停止局域网发现与连接。

游戏采用可爱惊悚风格，不含血腥暴力、语音聊天、养成或商业化内容。
```

## 3. 审核员 / 体验员最短路径

1. 一台手机联网启动，按服务界面完成隐私确认、平台账号登录及玩家验证。失败时手动重试或退出。
2. 点「单人游戏」，选阵营及小孩数量，等资源就绪后开始，验证移动、照射、抓捕、暂停与重新开始。
3. 两台手机连同一 Wi-Fi，各自登录验证并勾选局域网说明。A 创建房间，B 从附近房间、扫码或 6 位房间码加入。
4. 两人分别选鬼和小孩，由房主开始；验证右摇杆照明转向、结算、选角及准备下一局。
5. 对局中打开联机菜单，确认对局继续；检查声音开关、操作说明和退出确认。检查房间主机退出后其他玩家返回首页。
6. 检查取消登录、断网启动、验证失败均不能进入游戏；账号切换时旧对局退出并重新验证。单台设备无法开始多人对局，但可完整体验单人模式。
